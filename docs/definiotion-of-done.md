# Definition of Done

A milestone is done only when:

- [ ] All tasks and phases are complete; every milestone acceptance criterion is verified.
- [ ] Required checks pass; any not applicable are documented with a reason.
- [ ] `@adversary` review passes with no unresolved blocking findings.
- [ ] Milestone changes are committed using a Conventional Commit message.
- [ ] `docs/checkpoints.md` records the verified outcome and commit hash.

This checklist does not authorize a commit or invoke an adversary review; obtain explicit approval before either action.
